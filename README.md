# About

This is a Windows desktop application for recording visitor attendance. 
Visitors can enter their information, have their photo taken using a connected camera, and have their check-in information stored locally.

## How to install
1. Download `JonathanJenningsVisitorCheckIn-Setup.exe` [here](https://github.com/igarcia46/JJ-Check-Ins/releases/download/v1.0.3/JonathanJenningsVisitorCheckIn-Setup.exe).
2. Run the installer.
3. Follow the installation wizard.
4. Launch the application from the desktop or Start menu.
